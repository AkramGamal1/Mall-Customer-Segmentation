# Customer Segmentation using K-Means Clustering

This project focuses on customer segmentation by applying unsupervised machine learning techniques, particularly **K-Means Clustering**. The goal is to group customers based on their behaviors and characteristics to support targeted marketing, customer retention, and business strategy.

## 📊 Project Overview

- **Objective:** Segment customers into distinct groups based on key features.
- **Approach:** Use exploratory data analysis (EDA), scaling, and clustering to derive meaningful segments.
- **Algorithm Used:** K-Means Clustering

## 🧪 Features Used

The dataset contains customer-level information. Features include:
- Annual Income
- Spending Score
- Age
- (Possibly others depending on preprocessing)

## 🔍 Methodology

1. **Data Preprocessing:**
   - Handled missing values (if any)
   - Selected relevant features
   - Scaled data for clustering

2. **Exploratory Data Analysis:**
   - Visualizations for understanding distributions and correlations
   - Scatter plots and pair plots for initial insights

3. **Clustering:**
   - Elbow Method to determine the optimal number of clusters
   - Applied K-Means Clustering
   - Cluster visualization using 2D and 3D plots

4. **Insights:**
   - Interpreted cluster characteristics
   - Recommendations based on customer segments
